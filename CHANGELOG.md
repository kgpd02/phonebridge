# Changelog

## 0.1.0 — 2026-10-23

First public early-access release.

- Native macOS window with a local WebKit interface.
- USB iPhone discovery and installed-app inventory.
- Explicit iTunes metadata requests to recover numeric App Store IDs.
- Apple Account sign-in with two-factor input and visible progress.
- IPA download under an existing license, local import and SHA-256 deduplication.
- Bundle identifier verification before library import.
- Target-device confirmation before installation.
- Bundled Python runtimes for Apple Silicon and Intel.
- Mutable data stored in the user's Application Support folder.
- Universal macOS DMG and source release.

Validated: real iPhone inventory, Apple login and downloads of two delisted apps.
Not yet validated: installation and first launch on a second physical iPhone; a physical Intel Mac.
