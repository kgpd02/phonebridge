# Установка PhoneBridge для macOS

Нужна macOS 13 или новее. Сборка содержит версии для Apple Silicon и Intel.
Python включён в приложение. Отдельная установка Python не нужна.

1. Скачайте DMG из раздела Releases репозитория https://github.com/kgpd02/phonebridge.
2. Откройте DMG.
3. Перетащите PhoneBridge в папку «Программы».
4. Откройте PhoneBridge из папки «Программы».
5. Откройте раздел «О приложении».
6. Нажмите «Подготовить подключение».
7. Дождитесь загрузки компонентов с PyPI.

Первая подготовка требует доступа к интернету. Первый вход в Apple может занять несколько минут.

Сборка имеет локальную подпись ad-hoc. У неё нет сертификата Developer ID и нотариального заверения Apple.
macOS может заблокировать первое открытие. Проверьте адрес репозитория и контрольную сумму файла.
Для стандартного разрешения открытия следуйте инструкции Apple: https://support.apple.com/102445.
Не отключайте Gatekeeper целиком.

## Первый перенос

1. Подключите старый iPhone кабелем.
2. Разблокируйте iPhone.
3. Нажмите «Доверять», если iPhone покажет запрос.
4. Нажмите «Найти iPhone» в PhoneBridge.
5. Выберите старый iPhone.
6. Нажмите «Получить приложения».
7. Откройте раздел «Учётная запись Apple».
8. Нажмите «Войти в Apple».
9. Введите данные аккаунта, с которого вы получили приложение.
10. Введите код подтверждения, если Apple его запросит.
11. Нажмите «Скачать» у нужного приложения.
12. Проверьте App Store ID в окне загрузки.
13. Нажмите «Скачать IPA».
14. Дождитесь появления файла в «Библиотеке IPA».
15. Завершите активацию нового iPhone.
16. Подключите новый iPhone к Mac.
17. Нажмите «Найти iPhone».
18. Откройте «Библиотеку IPA».
19. Выберите новый iPhone в поле «Установить на».
20. Нажмите «Установить» у нужного файла.
21. Проверьте выбранный телефон в окне подтверждения.
22. Подтвердите установку.
23. Проверьте запуск приложения на новом iPhone.

Сохраните старый iPhone до проверки переноса.
IPA содержит приложение. Он не содержит его настройки, пароли или историю операций.

## Данные на Mac

Файлы IPA: ~/Library/Application Support/PhoneBridge/Library/
Компоненты подключения и cookies: ~/Library/Application Support/PhoneBridge/private/
Данные входа ipatool, включая пароль для обновления сессии: Связка ключей macOS.
При недоступности Связки ключей ipatool может предложить отдельное зашифрованное хранилище.

Выполните выход из ipatool в приложении, если хотите удалить его сохранённые данные входа.
Удаление PhoneBridge из «Программ» не удаляет библиотеку IPA или запись в Связке ключей.
