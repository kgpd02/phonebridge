# PhoneBridge — архив приложений iPhone на Mac

[English](README.md) · [Скачать DMG](https://github.com/kgpd02/phonebridge/releases) · [Инструкция](docs/INSTALL.ru.md)

PhoneBridge — открытое приложение для macOS. Оно читает список приложений iPhone, загружает доступные IPA с серверов Apple и хранит их в локальной библиотеке. Сохранённый IPA можно выбрать для установки на свой iPhone.

Приложение может исчезнуть из поиска App Store, но остаться доступным для загрузки по существующей лицензии. PhoneBridge получает числовой App Store ID из метаданных старого iPhone. Доступность загрузки определяет Apple.

## Для кого

Для владельцев iPhone, которым нужен локальный архив доступных приложений перед сменой телефона. В том числе для приложений, удалённых из поиска App Store.

## Как использовать

1. Установите PhoneBridge из DMG.
2. Подготовьте подключение в разделе «О приложении».
3. Подключите старый iPhone.
4. Получите список приложений.
5. Войдите в аккаунт Apple, которому принадлежит приложение.
6. Скачайте доступный IPA.
7. Подключите новый активированный iPhone.
8. Выберите его в библиотеке.
9. Подтвердите установку.

Подробные действия описаны в [инструкции](docs/INSTALL.ru.md).

## Состояние версии 0.1.0

Проверены чтение реального iPhone, вход с двухфакторным подтверждением и загрузка двух удалённых приложений. Идентификаторы и версии скачанных файлов совпали с приложениями на старом телефоне.

Установка и первый запуск на втором физическом iPhone пока не проверены. Сборка предназначена для раннего тестирования. Она содержит Python для Apple Silicon и Intel. Отдельный физический Intel Mac пока не проверен.

Подпись сборки — ad-hoc. Сертификата Developer ID и нотариального заверения Apple нет.

## Границы

PhoneBridge не извлекает установочный IPA из файлов приложения на современном iPhone. Он загружает пакет с Apple или импортирует ваш файл. Данные приложения, пароли и банковские сессии переносятся отдельно.

Вход выполняет ipatool. Он сохраняет данные аккаунта, включая пароль для обновления сессии, в Связке ключей macOS. Наш код не записывает пароль или код подтверждения в журнал. [Подробнее о хранении данных](docs/ARCHITECTURE.md).
