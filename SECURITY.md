# Reporting a security issue

Do not post Apple Account details, passwords, verification codes, cookies, full device identifiers or IPA receipts in public issues.

Use the repository's **Security → Report a vulnerability** feature if it is available. Otherwise open a minimal issue asking for a private reporting channel, without exploit details or private data.

This project is early access. There is no guaranteed response time. Its local HTTP boundary does not protect against another process already running as the same macOS user.
